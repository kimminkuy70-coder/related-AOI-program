AOI Photo Sorter v8 (GOOD 처리 사진 선별기)

용도
- 네트워크 폴더의 Reject 사진(폴더당 최대 1만 장)을 한 장씩 넘겨 보면서
  GOOD 처리할 사진만 Space로 골라내고, GOOD 목록 / REJECT 목록을 텍스트 파일 2개로 저장합니다.

실행 파일 (둘 중 하나)
- AOI_Photo_Sorter_v8.exe   설치 없이 바로 실행 (권장: 다른 사람에게 줄 때는 이 파일 하나만)
- AOI_Photo_Sorter_v8.vbs   ZIP 버전: 공용 Python 환경(AOI Matcher 등과 공유)을 써서 실행

.exe 로 실행 (설치 없음)
1. 릴리스에서 AOI_Photo_Sorter_v8.exe 를 받아 아무 로컬 폴더(바탕화면 등)에 둡니다.
2. 더블클릭합니다. Python, 패키지 설치가 필요 없습니다. (Windows 10/11에 기본으로 있는
   Microsoft Edge WebView2 Runtime만 사용)
3. 처음 실행할 때 Windows에 "Windows의 PC 보호" (SmartScreen) 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   (서명되지 않은 사내용 프로그램이라 처음 한 번 나타날 수 있습니다.)
   - 사내 백신이 실행을 막으면 IT 담당자에게 이 파일의 허용을 요청하세요.
- 실행할 때마다 .exe 안의 파일을 임시 폴더에 풀어 쓰므로, 창이 뜨기까지 1~3초 정도 걸릴 수 있습니다.
- 설정, 진행 상황, 로그 위치는 .vbs 버전과 같습니다(%LOCALAPPDATA%\AOI_Tools). 둘을 번갈아 써도 이어집니다.
  단, 두 버전을 동시에 실행할 수는 없습니다.

.vbs 로 실행 (ZIP)
1. ZIP 전체를 새 로컬 폴더에 압축 해제합니다.
2. AOI_Photo_Sorter_v8.vbs 를 더블클릭합니다.
3. 최초 1회만 "실행 환경 설치" 창이 나타납니다. AOI Matcher / Wafer Map Converter를 이미 쓰고 있다면
   같은 공용 환경을 재사용하므로 설치가 몇 초 만에 끝납니다.

사용 순서
1. 시작 화면에서 ① 사진 폴더, ② 결과 저장 위치를 지정합니다. (경로 붙여넣기 또는 [찾아보기])
   - ① 에 상위 폴더(예: LOT 폴더)를 지정하면 그 아래 사진이 있는 하위 폴더 목록이 나타납니다.
     아래 "상위 폴더로 작업 (하위 폴더별)"을 참고하세요.
   - 저장 위치는 시작할 때 실제로 파일을 써 보고 확인합니다. 쓸 수 없으면 시작되지 않습니다.
   - 저장 위치는 다음 실행 때도 기억합니다.
2. 시작(Enter). 모든 사진은 REJECT 상태로 시작합니다.
3. 선별 화면 키
     →          다음 사진 (REJECT 그대로)
     Space      지금 보이는 사진을 GOOD으로 바꾸고 다음 사진으로
                (이미 GOOD인 사진에서 누르면 GOOD 해제 + 다음 사진: 잘못 누른 것은 ← 후 Space)
     ←          이전 사진
     F, 휠, 드래그  100% 보기 / 화면 맞춤, 확대, 이동
     [연속 넘김]  위쪽 버튼으로 ON/OFF. ON이면 ←/→를 꾹 누르고 있는 동안 연속으로 넘어갑니다(초당 최대 10장).
                  다음 설정은 기억합니다. 사진마다 화면에 그려진 뒤 다음으로 넘어가므로 건너뛰는 사진은 없습니다.
     Home / End 첫 사진 / 작업 위치(아직 안 본 첫 사진)
     F5 (R, Ctrl+R) 새로고침: 네트워크 폴더에 다시 연결하고, 읽기 실패한 사진을 모두 다시 읽기
     Enter      (마지막 사진에서) 확인 화면으로
                상위 폴더 목록에서 연 하위 폴더는 "저장하고 다음 폴더로" 창 (아래 "상위 폴더로 작업" 참고)
     Esc        메뉴 (확인 화면으로 / 처음 화면으로)
   - GOOD 사진에는 왼쪽 위에 작은 "GOOD" 표시만 붙습니다(애니메이션 없음, 연타 시 렉 방지).
4. 확인 화면: GOOD 목록 썸네일을 확인하고, 클릭 또는 Space(다음 칸으로 이동)로 해제할 수 있습니다.
   [GOOD만 다시 넘겨보기], 화면에 한 번도 뜨지 않은 사진이 있으면 [미확인 사진 보기].
5. 저장(Ctrl+S): 미리 정한 위치에 결과 파일을 만듭니다(아래 "결과 파일" 참고).

결과 파일 (n차리뷰)
- 저장할 때마다 회차(n차리뷰)와 저장 날짜·시각이 붙은 새 파일을 만들고, 이전 회차 파일은 그대로 둡니다.
  이름: <사진폴더명>_<n>차리뷰_<날짜>_<시각>_<종류>.txt   예) LOT123_2차리뷰_20261010_1029_GOOD.txt
  상위 폴더 목록에서 연 하위 폴더는 <상위폴더명>_<하위폴더명>_… 입니다. 예) LOT123_Top_1차리뷰_20261014_0915_GOOD.txt
- 1차리뷰(처음 전체 리뷰): 2개
     ..._1차리뷰_날짜_시각_GOOD.txt      Space로 고른 사진
     ..._1차리뷰_날짜_시각_REJECT.txt    나머지 전부
- 2차리뷰부터(추가 GOOD 검토): 3개
     ..._n차리뷰_날짜_시각_추가GOOD.txt  이번 회차에서 새로 GOOD이 된 사진만
     ..._n차리뷰_날짜_시각_GOOD.txt      GOOD 전체(이전 GOOD + 이번 추가)
     ..._n차리뷰_날짜_시각_REJECT.txt    이번 회차 후에도 남은 REJECT
- 가장 큰 n이 최신입니다. 탐색기 이름순 정렬로 회차 순서대로 보입니다.
- 한 줄에 파일 이름 1개(확장자 포함), 폴더 정렬 순서(탐색기와 같은 순서), UTF-8, CRLF
- 같은 작업에서 다시 저장하면(확인 화면에서 고친 뒤 Ctrl+S 등) 새 회차를 만들지 않고 그 회차 파일을 갱신합니다.
- 결과가 있는 폴더에서 전체 리뷰를 처음부터 다시 하면 다음 번호의 회차로 저장되고 2개 파일을 만듭니다.
- v4까지의 결과 파일(<사진폴더명>_GOOD.txt / _REJECT.txt)은 이전 결과로 읽고, 지우거나 바꾸지 않습니다.

상위 폴더로 작업 (하위 폴더별)
- ① 사진 폴더에 상위 폴더를 지정하면 그 아래(4단계까지) 사진이 있는 폴더를 모두 찾아 목록으로 보여 줍니다.
  폴더마다 사진 수와 상태(미작업 / 진행 중 확인 수·GOOD 수 / n차리뷰 저장 / 추가 검토 중)가 표시됩니다.
  - 네트워크 폴더는 하위 폴더를 동시에 여러 개 읽으며, 찾는 대로 목록에 추가됩니다.
  - 숨김·시스템 폴더는 제외합니다. 상위 폴더 바로 아래에도 사진이 있으면 "(이 폴더)"로 함께 나옵니다.
- ↑ ↓ (PageUp/PageDown, Home/End)로 고르고 Enter, 또는 더블클릭으로 그 폴더를 시작합니다.
  고른 폴더의 저장 파일 이름, 이전 작업(이어하기), 이전 결과(추가 GOOD 검토)가 아래에 표시되고
  버튼도 그 폴더 기준으로 동작합니다.
- 하위 폴더 하나가 작업 하나입니다. 진행 상황, 결과 파일, 회차(n차리뷰), 추가 GOOD 검토가 폴더마다 따로입니다.
- 선별 화면 위쪽에 "상위폴더 › 하위폴더 (k/전체)"가 표시됩니다.
- 한 폴더를 끝까지 보면(마지막 사진에서 → / Space / Enter) "이 폴더의 마지막 사진입니다" 창이 뜹니다.
     Enter      이 폴더를 저장(n차리뷰)하고 바로 다음 하위 폴더로 넘어가 이어서 분류합니다.
                다음 폴더 화면 아래에 "이전 폴더 …: n차리뷰 저장 완료 (GOOD / REJECT)"가 잠깐 표시됩니다.
                마지막 폴더에서는 저장한 뒤 "전체 결과" 화면(아래)이 열립니다.
     C          확인 화면으로 (GOOD 썸네일 확인 후 Ctrl+S)
     Esc        창을 닫고 계속 보기
  - 미확인 사진이 있으면 창에 개수가 표시되고, 저장하면 REJECT로 들어갑니다.
- 확인 화면에서 저장(Ctrl+S)하면 완료 화면에 [다음 폴더: 이름 (Enter)]가 나옵니다. Enter 한 번으로 다음 하위 폴더를 시작합니다.
  (그 폴더에 이전 작업이 있으면 이어서 합니다.) Esc 메뉴의 [다음 폴더 (N)]로 저장 전에 넘어갈 수도 있습니다.
- Esc 메뉴의 [폴더 목록으로]나 완료 화면의 [폴더 목록으로]로 돌아가면 목록의 상태가 새로 고쳐집니다.
  사진이 새로 추가되었으면 F5(또는 [다시 읽기])로 폴더를 다시 읽습니다.
- 최근 작업 목록에는 상위 폴더가 기록되므로 클릭하면 목록이 다시 나타납니다.
- 같은 하위 폴더를 상위 폴더를 거치지 않고 직접 지정하면 결과 파일 이름은 하위 폴더명만으로(v5와 같이) 만듭니다.
  (진행 상황은 같은 폴더이므로 이어집니다.)

전체 결과 보기 (상위 폴더의 GOOD / REJECT 한 번에)
- 상위 폴더 아래 모든 하위 폴더의 결과(폴더마다 저장한 가장 큰 n차리뷰)를 한 화면에서 봅니다.
- 여는 방법: 마지막 폴더를 저장할 때 자동으로, 시작 화면 하위 폴더 목록의 [전체 결과 보기],
  완료 화면의 [전체 결과 보기], 선별 화면 Esc 메뉴의 [전체 결과 보기 (O)]
- 위쪽 [GOOD] / [REJECT] (키 1 / 2, Tab)로 바꿉니다. 사진마다 썸네일, 파일 이름, 하위 폴더 이름이 나옵니다.
- 왼쪽 목록: 전체 / 폴더별 GOOD·REJECT 개수. 클릭(또는 PageUp/PageDown)하면 그 폴더 사진만 봅니다.
  아직 저장하지 않은 폴더는 "저장 안 됨"으로 표시되고 사진은 나오지 않습니다.
- 방향키로 고르고 Enter(또는 더블클릭)로 크게 봅니다. 크게 보기에서 ← → 이전/다음, Esc 닫기.
- 아래쪽에 고른 사진의 전체 경로가 나옵니다. 끌어서 선택해 Ctrl+C 하거나 [경로 복사]를 누릅니다.
- F5(또는 [다시 읽기])로 결과 파일과 폴더를 다시 읽습니다. Esc로 폴더 목록으로 돌아갑니다.

사진 경로 패널 (선별 화면 왼쪽)
- 지금 보이는 사진의 폴더, 파일 이름, 전체 경로를 왼쪽에 표시합니다. 위쪽 [경로 패널 ON/OFF]로 켜고 끕니다(기억).
- 글자를 마우스로 끌어 선택한 뒤 Ctrl+C(또는 오른쪽 클릭 → 복사)로 복사할 수 있습니다. [경로 복사]는 전체 경로를 복사합니다.
- [이 사진 파일 끌어 놓기] 칸을 끌어서 탐색기 폴더나 바탕화면에 놓으면 그 사진 파일이 복사됩니다.
  메모장 등 글자 입력칸에 놓으면 전체 경로가 들어갑니다.
  (끌어 놓기가 안 되는 PC에서는 [경로 복사] 후 탐색기 주소창에 붙여 넣어 여세요.)
- 상위 폴더로 작업 중이면 하위 폴더 목록과 지금 폴더가 함께 표시됩니다.

추가 GOOD 검토
- 리뷰를 마친 뒤 REJECT로 남은 사진 중에서 GOOD을 더 고를 때 씁니다.
- 시작 화면에서 사진 폴더와 결과 저장 위치를 지정했을 때 그 위치에 이전 결과(가장 큰 n차리뷰)가 있으면
  "이전 결과: n차리뷰 · GOOD … / REJECT …" 안내와 [추가 GOOD 검토 시작 → (n+1)차리뷰] 버튼이 나타납니다.
  다른 PC에서 만든 결과 파일도 사용할 수 있습니다.
- 이전에 GOOD인 사진은 건너뛰고, REJECT로 남은 사진만 순서대로 넘겨 봅니다. 키 조작은 같습니다.
  - 위쪽에 "추가 검토" 표시와 "REJECT N장 중 k번째", "추가 GOOD n"이 표시됩니다.
  - 이전 결과를 저장한 뒤 폴더에 새로 생긴 사진도 검토 대상에 들어가고, 아래쪽에 "신규"가 붙습니다.
  - 결과 파일에는 있는데 폴더에서 사라진 사진은 제외하고 개수만 안내합니다.
  - 기존 GOOD은 이 모드에서 해제할 수 없습니다(추가만 가능).
- 확인 화면에는 이번에 추가한 GOOD만 썸네일로 나오고, 기존 GOOD은 개수만 표시됩니다.
- 저장하면 (n+1)차리뷰의 추가GOOD / GOOD / REJECT 3개 파일이 생깁니다. 이전 회차 파일은 그대로입니다.
  - 검토하는 사이에 다른 PC가 더 높은 회차를 저장했으면 저장 전에 알리고, 그 회차의 GOOD에
    이번 추가 GOOD을 합쳐 다음 번호로 저장합니다.
- 진행 상황은 일반 작업과 따로 자동 저장됩니다. 저장하지 않고 꺼졌으면 "추가 GOOD 검토 이어하기",
  [처음부터]로 새로 시작할 수 있습니다. 저장한 뒤 다시 하면 그 시점의 최신 결과 파일 기준으로 시작합니다.

빠른 연타 안정성
- 키 입력은 화면에서 즉시 처리하고, 저장은 뒤에서 묶어서 처리합니다.
- Space는 지금 화면에 그려진 사진에만 적용됩니다. 아직 뜨지 않은 사진은 GOOD이 되지 않습니다.
- 다음 사진이 아직 준비되지 않았으면 "불러오는 중"을 표시하고, 사진이 뜰 때까지 → 입력은 무시합니다.
  (입력을 쌓아 두었다가 한꺼번에 넘기지 않으므로, 모든 사진은 지나갈 때 반드시 한 번 화면에 뜹니다.)
- Space를 누르고 있어도 한 장만 처리됩니다. 사진이 화면에 뜬 지 0.12초가 안 된 상태의 Space는 무시하므로,
  키가 두 번 튀거나 겹쳐 눌려도 방금 넘어온 다음 사진이 GOOD이 되지 않습니다.
- 연속 넘김 OFF(기본)이면 방향키를 누르고 있어도 1장만 넘어갑니다. ON이면 초당 최대 10장씩 연속으로 넘어가고,
  다음 사진이 아직 준비되지 않았으면 준비될 때까지 기다립니다.
- 한/영, CapsLock 상태와 무관하게 동작합니다.

진행 상황 자동 저장 / 이어하기
- GOOD 지정과 확인 위치를 1초 단위로 %LOCALAPPDATA%\AOI_Tools\Photo_Sorter\sessions\ 에 저장합니다.
- 프로그램이 꺼져도 같은 사진 폴더를 다시 지정하면 "이전 작업 … 이어하기"로 계속할 수 있습니다.
  (사진 이름 기준으로 맞추므로 그사이 추가된 사진은 미확인, 삭제된 사진은 제외됩니다.)

네트워크 폴더 연결이 끊겼을 때
- 작업 중 연결이 끊겨도 프로그램은 멈추지 않고, 진행 상황(GOOD 지정, 확인 위치)도 그대로입니다.
- 이미 미리 읽어 둔 사진(앞쪽 최대 200장)은 계속 볼 수 있습니다.
- 아직 읽지 못한 사진에는 "네트워크 폴더 연결 끊김" 카드와 위쪽 빨간 안내가 뜹니다.
- 연결이 돌아오면 2초 안팎으로 자동으로 다시 읽어 이어집니다. 키를 누를 필요가 없습니다.
  (끊긴 동안 건너뛴 사진은 '미확인'으로 남으므로 End 키나 확인 화면의 [미확인 사진 보기]로 다시 볼 수 있습니다.)
- 자동으로 돌아오지 않거나 "읽기 실패"가 남아 있으면 F5(새로고침)를 누르세요. 실패한 사진을 모두 다시 읽습니다.
- 공유 폴더가 응답 없이 멈춰 있으면 위쪽에 노란색 "응답 대기 중" 안내가 뜹니다.
- 결과 저장 위치가 끊긴 네트워크 폴더이면 저장 실패 안내와 함께 다른 위치를 고를 수 있습니다.

느린 네트워크 폴더 대응
- 시작할 때 사진 목록만 읽고(사진 1만 장도 수 초) 첫 사진이 준비되면 바로 시작합니다.
- 현재 위치 앞 200장 / 뒤 50장을 8개 스레드가 병렬로 미리 읽어 메모리에 둡니다.
  (PC 메모리 8GB 이하이면 메모리 한도를 절반으로 줄입니다.)
- 화면 위쪽 오른쪽 점: 초록 = 미리 읽기 충분, 노랑 = 따라잡히는 중, 빨강 = 네트워크 대기

설정 (필요한 경우만)
- %LOCALAPPDATA%\AOI_Tools\Photo_Sorter\settings.json 을 메모장으로 수정합니다. (프로그램을 닫은 상태에서)
    read_threads       읽기 스레드 수 (기본 8, 2~16)
    ahead_count / ahead_bytes    앞쪽 미리 읽기 장수 / 바이트 (기본 200장 / 384MB)
    behind_count / behind_bytes  뒤쪽 유지 장수 / 바이트 (기본 50장 / 128MB)
    arrow_repeat       연속 넘김 (기본 false, 선별 화면의 [연속 넘김] 버튼과 같음)
    arrow_repeat_ms    연속 넘김 속도: 사진 1장당 최소 ms (기본 100 = 초당 10장)
    space_min_view_ms  사진이 화면에 뜬 뒤 Space를 받기까지의 최소 시간 ms (기본 120)
    path_panel         선별 화면 왼쪽 사진 경로 패널 (기본 true, [경로 패널] 버튼과 같음)

필요 조건
- Windows 10/11, Microsoft Edge WebView2 Runtime (Windows 11은 기본 포함)
- .vbs 버전만: Python 3.9 ~ 3.14 (64bit 권장). 없으면 실행 시 Python 3.12 자동 설치를 안내합니다.
  .exe 버전은 Python이 필요 없습니다.
- 대상 사진 형식: jpg, jpeg, png, bmp, tif, tiff (선택한 폴더 안의 사진만. 하위 폴더는 상위 폴더 목록에서 따로 작업)

문제 해결
- 실행 오류 로그: %LOCALAPPDATA%\AOI_Tools\logs\AOI_Photo_Sorter.log
- 화면 디버그: 환경변수 AOI_TOOLS_DEBUG=1 로 실행하면 WebView2 개발자 도구가 활성화됩니다.
- 사진 표시는 프로그램 내부의 로컬 서버(127.0.0.1, 실행마다 바뀌는 포트와 접근 토큰)를 사용합니다.
  사내 보안 프로그램이 127.0.0.1 통신을 막으면 사진이 뜨지 않을 수 있으니 로그와 함께 문의하세요.
