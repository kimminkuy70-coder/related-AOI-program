시험 순서

  1. 1 환경 정보는 자동으로 채워집니다.
  2. 2 네트워크 폴더 쓰기: 연결 방식(드라이브 문자 / UNC 주소)마다 폴더를 지정하고 [쓰기 시험]을 누르세요. 가장 중요한 시험입니다.
  3. 3 대체 저장 방법: 2가 막힐 때 쓸 수 있는 방법인지 확인합니다.
  4. 4 파일 넣기: 탐색기에서 맵 TXT 파일이나 폴더를 이 창에 끌어다 놓아 보세요. 네트워크 폴더에 있는 파일도 해 보세요.
  5. 5 맵 화면: 가짜 맵으로 확대·이동·실시간 갱신이 부드러운지 확인합니다.
  6. Edge를 완전히 닫았다가 이 파일을 다시 열어, 2에서 지정한 폴더와 권한이 남아 있는지 확인하세요.
  7. 위쪽 [결과 저장] 또는 [결과 복사]로 결과를 보내 주세요.

1환경 정보

이 PC와 브라우저가 변환기에 필요한 기능을 갖췄는지 자동으로 확인합니다.

2네트워크 폴더 쓰기 시험

실제 업로드처럼 맵 파일 크기(약 74 KB)의 시험 파일을 폴더에 쓰고, 다시 읽어 비교한 뒤 지웁니다.

  • 같은 폴더라도 드라이브 문자(Z:\…)로 고를 때와 UNC 주소(\\서버\공유\…)로 고를 때 결과가 다를 수 있어 따로 시험합니다. UNC 주소는 폴더 선택 창 위쪽 주소 칸에 붙여넣고 Enter를 누르면 됩니다.
  • 브라우저는 고른 폴더의 전체 경로를 알려 주지 않습니다. 결과를 알아보기 쉽게 경로 칸에 직접 적어 주세요.
  • 장비가 실제로 파일을 가져가는 폴더라면 시험 파일(__kla_camtek_write_test_….tmp)이 잠깐 생겼다가 지워집니다. 걱정되면 같은 공유 안의 다른 폴더로 먼저 시험하세요.
  • Edge가 파일 보기·수정 허용을 물으면 허용을 눌러 주세요. 확인 창이 몇 번 뜨는지도 결과에 기록됩니다.

3대체 저장 방법

2가 막혔을 때를 대비한 방법입니다. [저장 창으로 저장]을 누르고 업로드 폴더로 이동해 저장해 보세요.

4파일 넣기 시험

파일은 읽기만 하고 바꾸지 않습니다. 브라우저 보안상 전체 경로 대신 파일 이름(끌어 놓은 폴더 안의 경로)만 보입니다.

탐색기에서 맵 파일이나 폴더를 이 창 아무 곳에나 끌어다 놓으세요폴더를 놓으면 하위 폴더까지 읽습니다

5맵 화면 시험

가짜 웨이퍼 맵입니다. 오른쪽 결과 맵은 옵션을 바꾸는 즉시 다시 그려집니다.

6기록

모든 시험 결과가 여기에 쌓입니다. Edge를 닫았다 열어도 남아 있습니다.

이 페이지는 인터넷에 연결하지 않고, 파일을 외부로 보내지 않습니다. 시험 파일은 지정한 폴더에만 쓰고 지웁니다.
여기에 놓으면 파일 넣기 시험을 합니다
