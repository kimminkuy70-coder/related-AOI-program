AOI Photo Sorter HTML v2 (GOOD 처리 사진 선별기 — Edge에서 바로 실행)

무엇인가
- Python / .exe 버전과 같은 프로그램을 HTML 파일 하나로 만든 것입니다. 설치할 것이 없습니다.
- AOI_Photo_Sorter_HTML_v2.html 을 Microsoft Edge로 열면 바로 실행됩니다(Chrome도 가능).
- 화면과 키 조작, 미리 읽기, 결과 파일(n차리뷰), 추가 GOOD 검토, 상위 폴더(하위 폴더별 작업),
  전체 결과 보기, 연속 넘김, 경로 패널은 Python 버전 v10과 같습니다.
- 결과 파일 형식이 Python 버전과 같아서, 한쪽에서 저장한 결과를 다른 쪽에서 이어서 쓸 수 있습니다.
- v2 (#20): Esc 메뉴 창이 버튼 수(최대 6개)에 맞게 넓어지고, 좁으면 버튼이 다음 줄로 넘어갑니다.
  화면 오른쪽 위에 "개발자 : 김민규" 표시.

보안
- 실행되는 프로그램은 Edge뿐입니다. 이 파일은 Edge 안(샌드박스)에서만 동작합니다.
- 사용자가 [폴더 고르기]로 직접 고르고 허용한 폴더만 읽고 씁니다. 그 밖의 파일은 볼 수 없습니다.
- 페이지에 "어떤 네트워크 연결도 하지 않음" 규칙(Content Security Policy: connect-src 'none')이 들어 있어,
  사진이나 결과가 PC 밖으로 나갈 수 없습니다(브라우저가 강제).
- 사진 폴더는 읽기만 합니다. 결과 폴더에는 새 txt 파일만 만듭니다
  (사진 분류를 켜면 결과 폴더 안에 사진 복사본 폴더도 만듭니다. 아래 참고).
- TIFF 표시용으로 UTIF.js(MIT), pako(MIT) 코드를 파일 안에 포함했습니다(외부에서 불러오지 않음).

사용 순서
1. AOI_Photo_Sorter_HTML_v2.html 을 아무 폴더에 두고 Edge로 엽니다(더블클릭, 안 되면 Edge 창에 끌어 놓기).
2. ① 사진 폴더 [폴더 고르기] → 폴더 선택 창에서 사진 폴더(또는 상위 폴더)를 고릅니다.
   - 네트워크 폴더: 선택 창 위쪽 주소 칸에 \\서버\공유\폴더 를 붙여 넣고 Enter → [폴더 선택].
   - Edge가 "이 사이트에서 파일을 보도록 허용할까요?"를 물으면 [허용]을 누릅니다.
   - 브라우저는 입력한 경로를 스스로 열 수 없어서, 처음에는 반드시 [폴더 고르기]로 골라야 합니다.
     고른 뒤 이 칸의 이름을 전체 경로(\\서버\공유\LOT123)로 바꿔 두면 경로 패널·경로 복사에 그 경로가 쓰입니다.
3. ② 결과 저장 위치 [폴더 고르기] → 결과 폴더를 고르고, "파일 편집 허용"을 물으면 [허용]합니다.
4. 시작(Enter). 이후 키 조작은 Python 버전과 같습니다.
     →  다음 / Space  GOOD + 다음 / ←  이전 / F 100% / Home·End / F5 새로고침 / Esc 메뉴

사진 분류 (ON/OFF, 처음에는 OFF)
- 시작 버튼 아래 [사진 분류] 버튼, 또는 분류 화면 위쪽 [사진 분류] 버튼을 누를 때마다
  OFF → GOOD만 → 전체 → OFF 로 바뀝니다. 설정은 다음에 열 때도 그대로입니다.
- OFF: 결과 txt 파일만 저장합니다(지금까지와 같음). 사진 복사가 회사에서 막히거나 원하지 않으면 OFF로 쓰세요.
- GOOD만: 저장할 때 GOOD(2차부터는 추가GOOD도) 사진을, 결과 txt와 같은 이름의 폴더에 복사합니다.
    결과 폴더\LOT123_1차리뷰_20261015_0930_GOOD.txt
    결과 폴더\LOT123_1차리뷰_20261015_0930_GOOD\IMG_0001.jpg …
- 전체: REJECT 사진까지 복사합니다(사진 폴더 전체 용량만큼 필요하니 주의).
- 원본 사진은 읽기만 하고 옮기거나 지우지 않습니다. 복사는 저장 직후 뒤에서 진행되며
  (다음 폴더 작업을 바로 해도 됨) 분류 화면 위쪽과 저장 완료 화면에 진행 상황이 나옵니다.
- 같은 회차를 확인 화면에서 고쳐 다시 저장하면 폴더도 맞춰집니다(빠진 사진의 복사본은 지움.
  이 사진 폴더의 사진이 아닌 파일은 건드리지 않음).
- 이미 같은 이름·같은 크기의 파일이 있으면 다시 복사하지 않고, 크기가 다른 파일이 있으면 덮어쓰지 않고 건너뜁니다.
- 일부가 실패하면 저장 완료 화면의 [사진 분류 다시 실행]으로 나머지만 복사합니다.
  복사 중에 탭을 닫으면 복사가 멈춥니다(Edge가 한 번 묻습니다).

다음에 다시 열 때
- 진행 상황(GOOD 지정, 확인 위치)과 설정은 Edge 안(이 PC의 Edge 프로필)에 1초마다 저장됩니다.
- 시작 화면 "최근 작업"을 클릭하면 폴더가 다시 채워지고, Edge가 접근 허용을 한 번 더 묻습니다
  (보안 규칙상 브라우저를 다시 열 때마다 묻습니다). [폴더 접근 허용] 버튼이 보이면 누르세요.
- Edge의 "인터넷 사용 기록 삭제"에서 "쿠키 및 기타 사이트 데이터"를 지우면 진행 상황도 지워집니다.
  결과 txt 파일은 결과 폴더에 그대로 남으므로, 저장한 결과와 추가 GOOD 검토에는 영향이 없습니다.
- 진행 상황은 PC·브라우저마다 따로입니다(결과 txt는 공유 폴더에 두면 어느 PC에서나 이어짐).

Python 버전과 다른 점
- 설치·Python·.exe가 없습니다. Edge만 있으면 됩니다.
- 폴더는 입력이 아니라 [폴더 고르기]로 고릅니다. 브라우저를 열 때마다 접근 허용을 한 번 누릅니다.
- [결과 폴더 열기](탐색기 열기)는 없습니다. 결과 폴더는 탐색기에서 직접 여세요.
- 탭을 닫으려 하면 Edge가 한 번 묻습니다(진행 상황은 이미 저장되어 있음).
- Edge 회사 정책이 폴더 접근 기능(File System Access)을 막아 두었으면 실행되지 않습니다
  (시작할 때 안내 창이 뜹니다). 이때는 IT에 허용을 요청하거나 Python 버전을 쓰세요.

문제가 있을 때
- "폴더를 열 수 없습니다": 회사 정책으로 막혔거나, 시스템 폴더(바탕화면·다운로드 바로 위 등)를 고른 경우입니다.
  그 안의 사진 폴더를 고르세요.
- 사진이 안 뜨고 "네트워크 폴더 연결 끊김": 연결되면 자동으로 이어집니다. F5로 바로 다시 시도할 수 있습니다.

개발
- 원본: src/ (index.html, styles.css, app.js = 화면, backend.js = Python engine/server가 하던 일)
- 한 파일로 만들기: python tools/build_html.py   (검사: --check)
- 시험: python -m unittest tests.e2e_html_sorter -v   (Chromium, Playwright)
