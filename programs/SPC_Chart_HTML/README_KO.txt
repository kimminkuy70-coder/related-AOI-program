SPC Chart HTML v2 (엑셀 데이터 → 실시간 SPC 관리도, Edge에서 바로 실행)

무엇인가
- SPC_Chart_HTML_v2.html 을 Microsoft Edge로 열면 바로 실행됩니다 (Chrome도 가능). 설치할 것이 없습니다.
- 엑셀 시트(.xlsx / .xlsm / .csv)를 고르면 측정값을 관리도로 그리고,
  엑셀에서 값을 고쳐 저장(Ctrl+S)하면 몇 초 안에 차트가 저절로 바뀝니다 (기본 2초마다 파일 확인).
- 차트: I-MR (subgroup 1) 또는 Xbar-R (subgroup 2~25), 분포(히스토그램 + 정규분포 곡선).
- 선: USL/LSL(빨강 실선), UCL/LCL(주황 점선), CL(초록), ±1σ·±2σ(회색 점선).
- 통계: 평균, σ(within), Cp, Cpk, Ppk.

보안
- 페이지에 "어떤 네트워크 연결도 하지 않음" 규칙(connect-src 'none')이 들어 있어 데이터가 PC 밖으로 나가지 않습니다.
- 사용자가 [엑셀 열기]로 고른 파일만 읽습니다. 원본 엑셀 파일은 고치지 않습니다.
  추천값으로 고친 내용은 [수정본 엑셀 저장]으로 새 파일(복사본)에만 씁니다.
- xlsx 압축 풀기용 pako(MIT) 코드를 파일 안에 넣었습니다 (외부에서 불러오지 않음).

사용 순서
1. SPC_Chart_HTML_v2.html 을 Edge로 엽니다. [예제 보기]를 누르면 예제 데이터로 화면을 미리 볼 수 있습니다
   (예제는 몇 초마다 1점씩 늘어나 실시간 갱신을 흉내 냅니다).
2. [엑셀 열기] → 엑셀 파일 선택. Edge가 파일 보기를 물으면 [허용]. 파일을 창에 끌어 놓아도 됩니다.
3. 엑셀에서 데이터를 고치거나 줄을 추가하고 저장하면 차트가 바뀝니다.
   - 엑셀이 파일을 저장하는 순간에는 잠깐 못 읽을 수 있습니다. 그때는 위쪽 상태 글이 노랑/빨강이 되고 다음 확인 때 다시 읽습니다.
   - 다음에 열 때 [최근 파일 다시 열기]를 누르면 같은 파일을 다시 엽니다 (Edge가 다시 허용을 물음).
   - [실시간]을 끄면 자동 확인을 멈춥니다. [새로고침]은 지금 바로 다시 읽습니다.

엑셀 형식
- 첫 줄(값이 2칸 이상 있는 첫 줄)이 제목, 그 아래가 데이터입니다. 빈 줄은 건너뜁니다.
- 숫자 열은 자동으로 "측정값 열"이 되어 각각 차트가 됩니다 (위쪽 체크로 고름).
- 제목이 USL, LSL, UCL, LCL, CL(또는 Target, 목표, 중심선)인 열은 한계로 씁니다.
  줄마다 값이 다르면 그 값대로 선이 바뀌고, 빈 칸은 바로 위 값을 이어 씁니다.
  한계 열이 없으면 UCL/CL/LCL은 데이터로 계산합니다 (USL/LSL은 없으면 그리지 않음).
- 여러 항목이 한 열에 섞인 형식(날짜 · 항목 · 측정값 · USL · LSL)도 됩니다.
  제목이 "항목", "Item", "Parameter"인 열은 자동으로 [항목 열]이 되어 항목마다 차트를 따로 그립니다.
- X축: 제목이 날짜, 일자, 시간, Lot, Wafer 등인 열 (또는 첫 글자 열). [X축]에서 바꿀 수 있습니다.
- 수식 칸은 엑셀이 저장한 계산 결과 값을 읽습니다.
- SPC 시스템에서 내려받은 양식(한 줄 = 한 Lot, EXT_MV · EXT_MV_UCL · EXT_MV_CENTER · EXT_MV_LCL · USL · LSL · LOT_ID …)은
  자동으로 알아봅니다 (위쪽에 "SPC 시스템 양식" 표시): EXT_MV를 차트로, UCL/CL/LCL은 EXT_MV_UCL/CENTER/LCL 열,
  USL/LSL은 그 열, X축은 LOT_ID, 항목은 Item 열. 다른 숫자 열(EXT_SIGMA, CPK, VALUE_1 …)은 위쪽 체크로 더 그릴 수 있습니다.
- 확장자가 .xls/.xlsx여도 속이 HTML 표인 파일(일부 시스템이 이렇게 내려받음)도 읽습니다.
- .xls(옛 형식)는 못 읽습니다. 엑셀에서 .xlsx로 저장해 주세요.

관리한계
- I-MR: CL = 평균, UCL/LCL = 평균 ± 2.66 × MR평균 (σ = MR평균 / 1.128).
- Xbar-R: 연속 n개를 한 subgroup으로 묶음. UCL/LCL = Xbar평균 ± A2 × R평균. 끝에 n개가 안 찬 묶음은 다 찰 때까지 기다립니다.
- [한계 계산 점 수]: 처음 N점으로만 한계를 계산하고 고정합니다 (0 = 전체 데이터로 계속 다시 계산).
- 항목 카드의 [한계 설정]: USL, LSL, UCL, LCL, CL을 직접 넣으면 그 값으로 고정합니다 (비우면 엑셀 열 → 계산 순).
- 카드 아래 "한계 출처"에 각 선을 어디서 가져왔는지(엑셀 열 / 계산 / 직접 입력) 나옵니다.

판정 규칙 ([규칙 · OCAP 설정]에서 켜고 끄기, 점 수 바꾸기)
- 규격 이탈 (USL/LSL 밖, subgroup이면 묶음 안의 값 하나라도)          기본 켜짐
- 관리한계 이탈 (1점이 UCL/LCL 밖, MR/R 차트도 확인)                 기본 켜짐
- Run: 7점 연속 중심선 한쪽                                         기본 켜짐
- Trend: 7점 연속 상승 또는 하강                                    기본 켜짐
- 연속 3점 중 2점이 같은 쪽 2σ 밖                                   기본 켜짐
- 연속 5점 중 4점이 같은 쪽 1σ 밖                                   기본 켜짐
- 14점 연속 오르내림 반복 / 15점 연속 ±1σ 안 / 8점 연속 ±1σ 밖       기본 꺼짐
- 이상 점은 주황(관리 이탈), 빨강(규격 이탈)으로 표시합니다. 같은 규칙이 이어지는 점들은 한 건으로 셉니다.

OCAP (Out of Control Action Plan)
- 새로 저장된 데이터에서 새 이상이 나오면 위에 빨간 알림이 뜨고 소리가 납니다 (소리는 설정에서 끔).
  파일을 처음 열 때 이미 있던 이상은 알림 없이 목록에만 나옵니다.
- [OCAP 보기] 또는 "이상 목록 · OCAP" 표의 줄을 누르면 그 규칙의 조치 순서가 나옵니다.
  [조치 완료] 체크와 메모를 저장할 수 있습니다 (이 PC의 Edge에만 저장, 엑셀 파일에는 쓰지 않음).
- 규칙별 조치 내용은 [규칙 · OCAP 설정]에서 회사 기준에 맞게 고쳐 쓰세요 (처음 내용은 일반적인 예시).
- [CSV로 저장]: 이상 목록과 조치 상태를 CSV로 내려받습니다.

데이터 표 · 추천값 · 수정본 저장 (v2)
- 차트 아래에 엑셀 데이터가 그대로 표로 나옵니다 (맨 앞: 엑셀 행 번호, 판정, 차트로 그린 값 열. 그 뒤는 엑셀 열 순서 그대로).
- OCAP(규격 이탈 · 관리한계 이탈)와 7run(Run: 7점 연속 중심선 한쪽, Trend: 7점 연속 상승 · 하강)이 나온 행은 노란색입니다.
  [노란 행만]을 켜면 그 행만 봅니다. 규칙의 점 수와 켜기 · 끄기는 [규칙 · OCAP 설정]을 따릅니다.
- 차트의 점을 더블클릭하면 표의 그 행으로 이동하고 선택됩니다 (표의 행을 눌러도 선택).
- [선택 행 추천값 입력](주황): 선택한 행의 값을 추천값으로 바꿉니다.
  [전체 일괄 추천값 입력](보라): 노란 행 전체를 위에서부터 차례로 추천값으로 바꿉니다.
  바뀐 칸은 빨간색, 마우스를 올리면 원래 값이 보입니다. 차트도 바뀐 값으로 다시 그리고 바뀐 점에 빨간 테두리를 둡니다.
- 추천값 정하는 법: 그 점이 더 이상 OCAP · 7run에 걸리지 않고, 다른 점도 새로 걸리게 하지 않는 값 중에서
  ① 원래 값에서 중심선(CL) 쪽으로 조금씩 옮긴 값 (CL ± 2σ 안, 규격 안) → ② CL 바로 반대쪽 값 → ③ CL ± 2σ 안에서 원래 값과 가까운 값.
  7점 Run은 보통 7번째 점 하나만 고치면 풀립니다. 소수 자리는 그 열의 값과 같게 맞춥니다. 찾지 못하면 상태 글로 알려 주고 그대로 둡니다.
- [수정 모두 취소]: 추천값을 모두 되돌립니다.
- [수정본 엑셀 저장]: 원본은 그대로 두고 "원본이름_SPC수정_날짜_시각.xlsx" 새 파일로 저장합니다 (Edge가 저장 위치를 물음).
  원본 파일과 같은 이름을 고르면 저장하지 않습니다. 수정본에는 노란 행(노랑 채우기)과 고친 칸(빨강 채우기)이 그대로 들어가고,
  다른 시트 · 서식 · 수식은 원본과 같습니다 (고친 칸에 수식이 있었으면 값으로 바뀜, 열 때 수식을 다시 계산).
  .csv · HTML 표 파일은 새 .xlsx(시트 1개)로 만듭니다.
- 추천값은 subgroup 1 (I-MR)에서만 계산합니다. SPC 시스템 양식은 차트로 그린 값(EXT_MV)만 바꾸고,
  같은 행의 EXT_AVERAGE · VALUE_1 등은 그대로 둡니다.
- 엑셀에서 원본을 고쳐 저장해도 추천값은 유지됩니다. 단, 추천값을 넣은 칸의 원본 값이 바뀌었으면 그 추천값은 지웁니다.

알아 둘 것
- 설정, 한계 직접 입력, OCAP 기록은 Edge의 이 파일 저장소에 남습니다. 다른 PC나 다른 브라우저에는 따라가지 않습니다.
- 엑셀에서 파일을 연 채로 저장만 하면 됩니다 (자동 저장이 꺼진 로컬 파일이면 Ctrl+S).
