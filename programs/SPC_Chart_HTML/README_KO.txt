SPC Chart HTML v20 (정해진 기간의 엑셀 데이터 → SPC 관리도, Edge에서 바로 실행)

무엇인가
- SPC_Chart_HTML_v20.html 을 Microsoft Edge로 열면 바로 실행됩니다 (Chrome도 가능). 설치할 것이 없습니다.
- 실시간 감시가 아니라, 정해진 기간 동안의 데이터(엑셀 시트 .xlsx / .xlsm / .csv)를 SPC 차트로 보는 프로그램입니다.
- 기간 전체를 그립니다. 점이 많아 화면을 넘으면 차트 아래 가로 스크롤 막대(또는 Shift + 마우스 휠)로 넘겨 봅니다.
  XBAR와 SIGMA(또는 MR) 차트는 같이 움직이고, 왼쪽 Y축 눈금과 오른쪽 UCL/LCL 글자는 제자리에 있습니다.
  [점 간격]: 점 하나의 가로 폭 (기본 16 px). [화면에 맞춤]을 고르면 기간 전체를 한 화면에 모읍니다 (스크롤 없음).
  [표시 점 수]: 0 = 기간 전체 (기본), N = 마지막 N점만.
- 차트: I-MR (subgroup 1) 또는 Xbar-R (subgroup 2~25), 히스토그램.
- 선: USL/LSL(빨강 실선), UCL/LCL(주황 점선), CL(초록), ±1σ·±2σ(회색 점선).
- SPC 시스템 양식이면 SPC 시스템 화면처럼 XBAR 차트 + SIGMA 차트 (아래 "SPC 시스템 양식" 참고).
- 히스토그램: 막대 위에 도수(개수), 정규분포 곡선, 규격(USL/LSL, 빨강), 평균 ± 3σ(보라 점선, σ = 전체 표준편차).
- 통계: 평균, σ(within), Cp, Cpk, Ppk.

보안
- 페이지에 "어떤 네트워크 연결도 하지 않음" 규칙(connect-src 'none')이 들어 있어 데이터가 PC 밖으로 나가지 않습니다.
- 사용자가 [엑셀 열기]로 고른 파일만 읽습니다. 원본 엑셀 파일은 고치지 않습니다.
  추천값으로 고친 내용은 [수정본 엑셀 저장]으로 새 파일(복사본)에만 씁니다.
- xlsx 압축 풀기용 pako(MIT) 코드를 파일 안에 넣었습니다 (외부에서 불러오지 않음).

사용 순서
1. SPC_Chart_HTML_v20.html 을 Edge로 엽니다. [예제 보기]를 누르면 예제 데이터(300시간 기간)로 화면을 미리 볼 수 있습니다.
2. [엑셀 열기] → 엑셀 파일 선택. Edge가 파일 보기를 물으면 [허용]. 파일을 창에 끌어 놓아도 됩니다.
3. 엑셀에서 데이터를 고쳐 저장했으면 [새로고침]을 누르면 다시 읽습니다.
   [자동 새로고침]은 v13에서 없앴습니다 (#29, 정해진 기간의 데이터를 보는 프로그램).
   - 엑셀이 파일을 저장하는 순간에는 잠깐 못 읽을 수 있습니다. 그때는 위쪽 상태 글이 노랑/빨강이 되니 잠시 뒤 [새로고침]을 다시 누릅니다.
   - 위쪽 "SPC Chart" 옆에 지금 보고 있는 파일 이름이 나옵니다 (시트가 여러 개면 시트 이름도). v16 (#32)
   - [최근 파일 다시 열기] 버튼은 v16에서 없앴습니다 (#32). 다음에도 [엑셀 열기]로 파일을 고릅니다.
   - 아래 데이터 표에서 행을 누르면 차트도 그 점이 보이도록 옆으로 넘어갑니다.

엑셀 형식
- 첫 줄(값이 2칸 이상 있는 첫 줄)이 제목, 그 아래가 데이터입니다. 빈 줄은 건너뜁니다.
- 숫자 열은 자동으로 "측정값 열"이 되어 각각 차트가 됩니다 (위쪽 체크로 고름).
- 제목이 USL, LSL, UCL, LCL, CL(또는 Target, 목표, 중심선)인 열은 한계로 씁니다.
  줄마다 값이 다르면 그 값대로 선이 바뀌고, 빈 칸은 바로 위 값을 이어 씁니다.
  한계 열이 없으면 UCL/CL/LCL은 데이터로 계산합니다 (USL/LSL은 없으면 그리지 않음).
- 여러 항목이 한 열에 섞인 형식(날짜 · 항목 · 측정값 · USL · LSL)도 됩니다.
  제목이 "항목", "Item", "Parameter"인 열은 자동으로 [항목 열]이 되어 항목마다 차트를 따로 그립니다.
- X축: 제목이 날짜, 일자, 시간, Lot, Wafer 등인 열 (또는 첫 글자 열). [X축]에서 바꿀 수 있습니다.
- 수식 칸은 엑셀이 저장한 계산 결과 값을 읽습니다.
- SPC 시스템에서 내려받은 양식(한 줄 = 한 Lot, EXT_MV · EXT_MV_UCL · EXT_MV_CENTER · EXT_MV_LCL · USL · LSL · LOT_ID …)은
  자동으로 알아봅니다 (위쪽에 "SPC 시스템 양식" 표시). 항목은 Item 열.
  · XBAR 차트: EXT_MV. 선은 UCL/LCL(EXT_MV_UCL/LCL 열, 주황 점선)과 CL(EXT_MV_CENTER, 파란 점선, v20 #34)을 그립니다
    (USL/LSL 선 없음, 판정에는 USL/LSL도 씀).
    EXT_MV_CENTER(CL) 칸이 비어 있으면 SIGMA 차트와 똑같이 Run(7run) · Trend는 판정하지 않고 규격 · 관리한계 이탈만 봅니다
    (v18, #34. 전에는 UCL/LCL 가운데를 CL로 계산해 판정했음). 차트 제목에 "CL 없음"이 나옵니다. SPC 시스템 양식이 아닌 엑셀은 그대로 계산 CL을 씁니다.
  · SIGMA 차트: XBAR 바로 아래에 EXT_SIGMA, 선은 EXT_SIGMA_UCL/LCL(주황 점선)과 CL(EXT_SIGMA_CENTER, 파란 점선, v20 #34). v6부터 XBAR처럼 판정합니다:
    OCAP = EXT_SIGMA_UCL/LCL 밖, 7run = EXT_SIGMA_CENTER 기준 7점 연속 한쪽, Trend = 6점 연속 상승/하강 (규칙 이름 앞에 "SIGMA").
    걸린 점은 주황, 그 행은 노란색, 이상 목록(OCAP)에도 나옵니다. v13부터 규칙 켜기 · 점 수는 [규칙 · OCAP 설정]의
    "SIGMA 차트" 칸에서 XBAR와 따로 정합니다 (#29).
    EXT_SIGMA_CENTER(CL) 칸이 비어 있으면 SPC 시스템처럼 SIGMA Run(7run) · Trend는 판정하지 않고 관리한계 이탈만 봅니다
    (v17, #33. 전에는 UCL/LCL 가운데를 CL로 계산해 판정해서, 시스템에 없는 7run · 6 Trend가 나왔음). 차트 제목에 "CL 없음"이 나옵니다.
  · X축: 날짜 · 시간 (TRAN_TIME, 없으면 수정일시, 없으면 LOT_ID). 날짜 아래에 시각을 두 줄로 씁니다. LOT_ID는 점에 마우스를 올리면 보입니다.
  · 다른 숫자 열(CPK, VALUE_1 …)은 위쪽 체크로 더 그릴 수 있습니다 (그 열은 보통 관리도로 그림).
- 확장자가 .xls/.xlsx여도 속이 HTML 표인 파일(일부 시스템이 이렇게 내려받음)도 읽습니다.
- 다른 프로그램(SPC 시스템 등)이 만든 .xlsx도 읽습니다: 안의 부분 이름이 엑셀과 달라도(대소문자, '\' 구분, workbook 이름) 엑셀처럼 찾습니다 (v5, #25).
  .ods(OpenDocument)도 읽습니다. 그래도 못 읽으면 오류 글에 파일 안에 든 이름이 나오니 그 글을 알려 주세요.
- .xls(옛 형식)는 못 읽습니다. 엑셀에서 .xlsx로 저장해 주세요.
- .xlsb(엑셀 바이너리)도 못 읽습니다. 엑셀에서 .xlsx로 저장해 주세요.

관리한계
- I-MR: CL = 평균, UCL/LCL = 평균 ± 2.66 × MR평균 (σ = MR평균 / 1.128).
- Xbar-R: 연속 n개를 한 subgroup으로 묶음. UCL/LCL = Xbar평균 ± A2 × R평균. 끝에 n개가 안 찬 묶음은 다 찰 때까지 기다립니다.
- [한계 계산 점 수]: 처음 N점으로만 한계를 계산하고 고정합니다 (0 = 전체 데이터로 계속 다시 계산).
- 항목 카드의 [한계 설정]: USL, LSL, UCL, LCL, CL을 직접 넣으면 그 값으로 고정합니다 (비우면 엑셀 열 → 계산 순).
- 카드 아래 "한계 출처"에 각 선을 어디서 가져왔는지(엑셀 열 / 계산 / 직접 입력) 나옵니다.

판정 규칙 ([규칙 · OCAP 설정]에서 차트마다 켜고 끄기, 점 수 바꾸기; v13부터 XBAR 차트와 SIGMA 차트를 따로 설정, #29)
XBAR 차트 (SPC 시스템 양식이 아니면 값 차트)
- 규격 이탈 (USL/LSL 밖, subgroup이면 묶음 안의 값 하나라도)          기본 켜짐 (OCAP)
- 관리한계 이탈 (1점이 UCL/LCL 밖, MR/R 차트도 확인)                 기본 켜짐 (OCAP)
- Run: 7점 연속 중심선 한쪽                                         기본 켜짐 (7run)
- Trend: 6점 연속 상승 또는 하강                                    기본 꺼짐 (v13부터, 켜면 6점)
- 연속 3점 중 2점이 같은 쪽 2σ 밖                                   기본 꺼짐 (v8부터)
- 연속 5점 중 4점이 같은 쪽 1σ 밖                                   기본 꺼짐 (v8부터)
- 14점 연속 오르내림 반복 / 15점 연속 ±1σ 안 / 8점 연속 ±1σ 밖       기본 꺼짐
- SPC 시스템 양식에서 EXT_MV_CENTER(CL)가 비어 있으면 Run · Trend는 판정하지 않음 (켜 있어도, v18 #34)
SIGMA 차트 (SPC 시스템 양식의 EXT_SIGMA)
- 관리한계 이탈 (EXT_SIGMA_UCL/LCL 밖)                              기본 켜짐 (OCAP)
- Run: 7점 연속 중심선 한쪽                                         기본 켜짐 (7run)
- Trend: 6점 연속 상승 또는 하강                                    기본 켜짐
- EXT_SIGMA_CENTER(CL)가 비어 있으면 Run · Trend는 판정하지 않음 (켜 있어도, v17 #33)
- 이상 점은 주황(관리 이탈), 빨강(규격 이탈)으로 표시합니다. 같은 규칙이 이어지는 점들은 한 건으로 셉니다.
- OCAP 조치 문구는 규칙마다 하나이고 두 차트가 같이 씁니다. [기본값으로]를 누르면 위 기본값으로 돌아갑니다.
- 옛 버전에서 쓰던 설정은 v13을 처음 열 때 XBAR Trend만 한 번 끄고, SIGMA는 위 기본값으로 시작합니다.

  파일을 처음 열 때 이미 있던 이상은 알림 없이 목록에만 나옵니다.
- [OCAP 보기] 또는 "이상 목록 · OCAP" 표의 줄을 누르면 그 규칙의 조치 순서가 나옵니다.
  [조치 완료] 체크와 메모를 저장할 수 있습니다 (이 PC의 Edge에만 저장, 엑셀 파일에는 쓰지 않음).
- 규칙별 조치 내용은 [규칙 · OCAP 설정]에서 회사 기준에 맞게 고쳐 쓰세요 (처음 내용은 일반적인 예시).
- [CSV로 저장]: 이상 목록과 조치 상태를 CSV로 내려받습니다.

데이터 표 · 추천값 · 수정본 저장 (v2부터)
- 차트 아래에 엑셀 데이터가 그대로 표로 나옵니다 (맨 앞: 엑셀 행 번호, 판정, 차트로 그린 값 열. 그 뒤는 엑셀 열 순서 그대로).
- 표의 숫자 · 날짜는 엑셀 화면과 같은 모양으로 보입니다 (v19, #34): 엑셀 표시 형식대로 소수 자리(64.9600, 67.420, 0.644), %, 천 단위 쉼표,
  시각은 엑셀처럼 초 단위로 반올림. 엑셀에서 숨긴 열(SPC 시스템 export의 A열)은 표에서도 숨깁니다.
  계산(차트, 판정, 추천값)은 지금처럼 칸의 실제 값(예: CL 0.643636, UCL 67.4204358656)을 씁니다. 엑셀도 화면만 반올림하고 계산은 실제 값으로 합니다.
- OCAP(규격 이탈 · 관리한계 이탈)와 7run(Run: 7점 연속 중심선 한쪽, Trend: 6점 연속 상승 · 하강; 기본값은 XBAR = OCAP · Run, SIGMA = OCAP · Run · Trend)이 나온 행은 노란색입니다.
  [노란 행만]을 켜면 그 행만 봅니다. 규칙의 점 수와 켜기 · 끄기는 [규칙 · OCAP 설정]을 따릅니다.
- 차트의 점을 더블클릭하면 표의 그 행으로 이동하고 선택됩니다 (표의 행을 눌러도 선택).
- [선택 행 추천값 입력](주황): 선택한 행의 값을 추천값으로 바꿉니다.
  [시뮬레이션] → [행 수정만] (v15 전에는 [전체 일괄 추천값 입력]): 노란 행 전체를 위에서부터 차례로 추천값으로 바꿉니다.
  바뀐 칸은 빨간색, 마우스를 올리면 원래 값이 보입니다. 차트도 바뀐 값으로 다시 그리고 바뀐 점에 빨간 테두리를 둡니다.
- 추천값 정하는 법: 그 점이 더 이상 OCAP · 7run에 걸리지 않고, 다른 점도 새로 걸리게 하지 않는 값 중에서
  ① 원래 값에서 중심선(CL) 쪽으로 조금씩 옮긴 값 (CL ± 2σ 안, 규격 안) → ② CL 바로 반대쪽 값 → ③ CL ± 2σ 안에서 원래 값과 가까운 값.
  7점 Run은 보통 7번째 점 하나만 고치면 풀립니다. 소수 자리는 그 열의 값과 같게 맞춥니다. 찾지 못하면 상태 글로 알려 주고 그대로 둡니다.
  그 점 값만으로는 안 풀릴 때가 있습니다 (v7): 예를 들어 Run 7번째 점을 CL 반대쪽으로 옮기면 바로 다음 점과 함께 연속 하강(Trend)이
  새로 생기는 경우. 이때는 같은 Run/Trend 안의 앞 점(최대 6점 앞) 중 가장 조금 움직이면 되는 점을 대신 고치고 상태 글에 그 행을 알려 줍니다.
- [수정 모두 취소]: 추천값을 모두 되돌립니다.
- [수정본 엑셀 저장]: 원본은 그대로 두고 "원본이름_SPC수정_날짜_시각.xlsx" 새 파일로 저장합니다 (Edge가 저장 위치를 물음).
  원본 파일과 같은 이름을 고르면 저장하지 않습니다. 수정본에는 노란 행(노랑 채우기)과 고친 칸(빨강 채우기)이 그대로 들어가고,
  다른 시트 · 서식 · 수식은 원본과 같습니다 (고친 칸에 수식이 있었으면 값으로 바뀜, 열 때 수식을 다시 계산).
  .csv · HTML 표 파일은 새 .xlsx(시트 1개)로 만듭니다.
- 추천값은 subgroup 1 (I-MR)에서만 계산합니다. SPC 시스템 양식은 두 차트를 같이 봅니다 (v6):
  XBAR에 걸린 행은 EXT_MV, SIGMA에 걸린 행은 EXT_SIGMA, 둘 다 걸린 행은 두 칸을 같이 고쳐 두 차트 모두에서 풀리게 합니다.
  EXT_SIGMA 추천값도 같은 방법(SIGMA CL ± 2σ 안, 0 이상)으로 정합니다. 표에서 판정 오른쪽에 EXT_MV · EXT_SIGMA 열이 같이 보입니다.
  같은 행의 EXT_AVERAGE · VALUE_1 등 원 데이터는 그대로 둡니다.
- 엑셀에서 원본을 고쳐 저장해도 추천값은 유지됩니다. 단, 추천값을 넣은 칸의 원본 값이 바뀌었으면 그 추천값은 지웁니다.

화면 배치와 [시뮬레이션] (v15, #31)
- 위쪽 "측정값 열"은 접혀 있습니다 (기본). 줄을 누르면 펼쳐져 차트로 그릴 숫자 열을 고르고, 다시 누르면 접힙니다.
  접혀 있어도 지금 그리는 열 이름 · 개수와 SPC 시스템 양식 표시, 한계 열이 보입니다.
- 데이터 표 위 버튼: [선택 행 추천값 입력] | [시뮬레이션 ▾]. 짧은 세로선으로 나눴습니다.
  [시뮬레이션]을 누르면 하위 버튼 3개가 나옵니다 (한 번에 하나만 켜지고, 켜진 버튼을 다시 누르면 원래대로):
  · 행 삭제만 = 예전 [삭제 시뮬레이션] (아래). 결과 상자의 [OCAP 삭제 양식 엑셀 저장].
  · 행 수정만 = 예전 [전체 일괄 추천값 입력]. 파일 원래 값에서 노란 행을 모두 추천값으로 고칩니다.
    결과 상자에 고친 행 목록, [RAW_DATA 수정 양식 엑셀 저장], [수정 목록 CSV]. 끄면 켜기 전의 수정으로 돌아갑니다.
  · 최소 행 변경 (삭제+수정) = 예전 [최소 행 변경] (아래). 결과 상자의 [양식 2개 엑셀 저장 (삭제 + 수정)]을 누르면
    저장할 폴더를 한 번 고르면, 그 안에 SPEC_SEQ 이름의 폴더를 만들고(이미 있으면 그 폴더) 그 안에
    "OCAP 삭제 양식_(SPEC_SEQ)_yyyymmddhhmm.xlsx"(삭제할 행)와 "RAW_DATA 수정 양식_(SPEC_SEQ)_yyyymmddhhmm.xlsx"(값을 고친 행)를 각각 저장합니다 (v16, #32).
    (Edge가 폴더 수정 허용을 물으면 [허용]. 삭제나 수정 중 한쪽이 없으면 있는 쪽 파일 하나만 저장합니다.)
  켜 있는 동안 [선택 행 추천값 입력]은 쓸 수 없습니다.
- [수정 모두 취소] · [수정본 엑셀 저장] · [수정 양식 저장]은 데이터 표 아래에 있습니다.
- 데이터 표 복사: 표에서 마우스를 누른 채 끌어 칸을 고르고(파란색, Shift+클릭으로 넓히기) Ctrl+C (또는 [고른 칸 복사]) →
  엑셀에서 Ctrl+V 하면 화면처럼 노란 행 · 빨간 칸 · 회색 삭제 행 · 머리글 색과 글자가 그대로 들어갑니다.
  숫자는 숫자로, 날짜 · LOT 같은 글자는 화면에 보이는 글자 그대로(텍스트) 들어갑니다. 머리글 줄도 고를 수 있습니다.

삭제 시뮬레이션 (v9, #27)
- 노란 행(OCAP · 7run)을 지우면 그 앞뒤 점이 이어져 다른 곳에서 OCAP · 7run이 새로 생길 수 있습니다.
  [시뮬레이션] → [행 삭제만]을 누르면 계산합니다 (v11부터 한 행씩, v15 전에는 [삭제 시뮬레이션] 버튼):
  가장 앞(엑셀 위쪽) 노란 행 하나를 지우고 → XBAR · SIGMA를 다시 판정 → 다음 걸린 행을 지우고 … 를 걸리는 행이 없을 때까지.
  앞 행을 지우면 Run이 6점으로 짧아져 저절로 풀리는 노란 행은 지우지 않으므로, 한꺼번에 지우던 v9 · v10보다 지울 행이 적습니다.
  1차 = 노란 행 중 실제로 지워야 하는 행, 2차 = 1차를 지운 뒤에야 새로 걸리는 행, 3차 … 로 나눠 보여 줍니다.
- 표 위 상자에 차수마다 지울 엑셀 행 번호가 나오고(누르면 그 행으로 이동), 마지막에
  "모두 N행을 지우면 XBAR · SIGMA 차트 모두 OCAP · 7run이 나오지 않습니다"처럼 결론을 알려 줍니다.
- 켜 있는 동안 차트는 그 행들을 지운 모습, 표에서 지운 행은 회색 취소선 + "삭제 1차/2차 …" 표시입니다.
  [행 삭제만]을 다시 누르면 원래대로 돌아옵니다. 원본 파일은 바꾸지 않습니다.
- [삭제 목록 CSV]: 차수, 엑셀 행, X축, LOT_ID, 판정을 CSV로 저장합니다 (엑셀에서 이 행들을 직접 지울 때 참고).
- 한 행을 지우면 그 행의 XBAR 점과 SIGMA 점이 같이 빠집니다. 판정 규칙 켜기 · 점 수는 [규칙 · OCAP 설정]을 따릅니다.
- 파일 원래 값으로 계산합니다 (추천값으로 고친 칸은 빼고). 켜 있는 동안 추천값 버튼은 쓸 수 없습니다.
- 관리한계를 엑셀 열(EXT_MV_UCL 등)에서 가져오면 행을 지워도 한계는 그 행들 값 그대로이고,
  데이터로 계산하는 한계(한계 열 없음)는 지운 뒤 데이터로 다시 계산합니다.
- 한 행씩 앞에서부터 지우는 방법이라 v9 · v10보다 적게 지우지만, 수학적으로 가장 적은 조합이라는 보장은 없습니다.

OCAP 삭제 양식 저장 (v10, #28 / v14 소유자 양식 파일대로, #30)
- [시뮬레이션] → [행 삭제만]을 켠 뒤 상자 오른쪽 [OCAP 삭제 양식 엑셀 저장]을 누르면, 지울 행을 회사 OCAP 삭제 양식 엑셀로 저장합니다
  ([최소 행 변경]에서는 [양식 2개 엑셀 저장]에 같이 들어감).
  [수정본 엑셀 저장], [삭제 목록 CSV]와는 별개의 새 파일이고 원본은 바꾸지 않습니다.
- 파일 이름: "OCAP 삭제 양식_(SPEC_SEQ)_yyyymmddhhmm.xlsx" (v16, #32. 예: OCAP 삭제 양식_129588_202610211130.xlsx).
  SPEC_SEQ는 양식에 들어가는 행의 SPEC_SEQ 값. 값이 여러 개면 '+'로 이음 (예: 129588+130121), SPEC_SEQ 열이 없으면 시트 이름.
- v14부터 소유자가 준 양식 파일 그대로 (시트 하나 "Sheet1"):
  B2 제목 "OCAP 삭제 양식", 5행 "OCAP 전체 삭제 시 / OCAP 일부 삭제 시 / 요청 사항", 6행 회색 머리글 "EDC Plan / Spec seq# / Data seq# / 요청 내용",
  7행부터 지울 행마다 한 줄: EDC Plan(PLAN_NAME), Spec seq#(SPEC_SEQ), Data seq#(DATA_SEQ),
  요청 내용 = "Data 자체를 완전 삭제 & 히스토리 삭제 (Data 자체 완전 삭제". 26행까지 빈 테두리 줄. 열 너비도 양식대로.
  (v12 · v13의 [Option] 상자와 Spec seq#별 시트는 없앴습니다.)
- PLAN_NAME 열이 없으면 EDC Plan 칸에 항목(Item) 이름을 씁니다. SPEC_SEQ · DATA_SEQ 열이 없으면 그 칸은 비어 있습니다.

수정 양식 저장 (v14, #30)
- 값을 고친 행(빨간 칸: 추천값, [행 수정만], [최소 행 변경])을 회사 RAW_DATA 수정 양식 엑셀로 저장합니다. 데이터 표 아래 [수정 양식 저장]
  또는 [행 수정만] 결과 상자의 [RAW_DATA 수정 양식 엑셀 저장].
  파일 이름 "RAW_DATA 수정 양식_(SPEC_SEQ)_yyyymmddhhmm.xlsx" (v16, #32), 시트 "Sheet1", 소유자가 준 양식 그대로:
  B2 "S/S 25>", 3행 머리글 DATA_SEQ# · Raw Value 1~25 · MAX · MIN · AVG · STD(색 · 굵은 12pt), 4행부터 고친 행마다 노란 한 줄.
- SPC 시스템은 원 데이터 25개(VALUE_1~25)로 EXT_MV · EXT_SIGMA를 계산하므로, 새 Raw Value는
  원래 25개 값을 EXT_MV가 바뀐 만큼 옮기고 EXT_SIGMA가 바뀐 비율만큼 평균 둘레로 늘이거나 줄인 값입니다 (모양은 같고 평균 · 산포만 바뀜).
  소수 4자리(원 데이터가 더 길면 그 자리)로 반올림하고, MAX · MIN · AVG · STD는 새 값으로 계산해 넣습니다.
  STD는 파일의 EXT_SIGMA가 표본 표준편차와 모집단 표준편차 중 어느 쪽에 가까운지 보고 같은 방식으로 계산합니다.
- 파일에 VALUE_1~25 열이 없으면 Raw Value 칸은 비우고 AVG = 새 값, STD = 새 EXT_SIGMA만 씁니다.

최소 행 변경 (v14, #30)
- [시뮬레이션] → [최소 행 변경 (삭제+수정)]: 삭제만이 아니라 값 수정까지 섞어서, 바꾸는 엑셀 행 수(지우는 행 + 값을 고치는 행)가 가장 적게
  XBAR · SIGMA 차트 모두 OCAP · 7run이 없어지는 방법을 계산하고 바로 적용합니다. 한 행의 EXT_MV와 EXT_SIGMA를 같이 고치면 1행으로 셉니다.
- 계산 방법: 가장 앞의 걸린 행부터, 그 행 삭제 / 그 행 값 수정 / (Run · Trend면) 같은 런의 앞 점 삭제 · 값 수정을 모두 해 보고
  남는 걸린 행이 가장 적은 것을 고름 (같으면 값 수정, 그 행 자신 우선). 다 끝나면 빼도 되는 변경은 다시 뺍니다.
  마지막으로 [행 삭제만], [행 수정만] 결과와 비교해 가장 적은 쪽을 씁니다 (상자에 세 가지 행 수가 나옴).
  가장 적은 조합을 수학적으로 보장하지는 않지만, 두 버튼 하나만 쓰는 것보다 많지 않습니다.
- 켜면 고칠 값은 빨간 칸(수정본 · 수정 양식에 들어감), 지울 행은 회색 취소선("삭제")으로 보이고 차트는 바꾼 뒤 모습입니다.
  끄면 켜기 전의 수정으로 되돌립니다. 파일 · 시트 · 열 · 규칙을 바꾸면 계산은 끝나고 고친 값만 빨간 칸으로 남습니다.
- [변경 목록 CSV]: 구분(삭제/값 수정), 엑셀 행, X축, LOT_ID, 열, 원래 값, 새 값, 판정.
- 파일 원래 값 기준, subgroup 1 (I-MR)에서만. 행이 1,000개 넘으면 몇 초 걸릴 수 있습니다.

설정 저장 (v14, #30)
- 위쪽 [설정 저장]: 지금 설정(판정 규칙 · 점 수, OCAP 문구, 한계 직접 입력, 시트 · 열 선택, 점 간격, 표시 점 수, subgroup, 소리)을
  이 PC의 Edge와 설정 파일("SPC_Chart_설정.json", 처음 한 번 저장 위치를 물음, 다음부터는 같은 파일에 덮어씀)에 저장합니다.
  다음에 프로그램을 열면 저장한 설정으로 시작합니다.
- 회사 PC가 Edge를 닫을 때 기록을 지우게 되어 있으면 브라우저 저장이 사라집니다. 그때는 [설정 불러오기]로 그 설정 파일을 엽니다.
- 설정은 바꿀 때마다 브라우저에도 자동으로 저장됩니다 (전과 같음). [설정 저장]은 확실히 남기고 파일로도 보관하는 버튼입니다.

알아 둘 것
- 설정, 한계 직접 입력, OCAP 기록은 Edge의 이 파일 저장소에 남습니다. 다른 PC나 다른 브라우저로는 [설정 저장]의 설정 파일을 [설정 불러오기]로 옮깁니다 (OCAP 기록은 옮기지 않음).
- 엑셀에서 파일을 연 채로 저장하고 [새로고침]을 누르면 됩니다 (자동 저장이 꺼진 로컬 파일이면 Ctrl+S).
