## AOI Photo Sorter v1 — GOOD 처리 사진 선별기

네트워크 폴더의 Reject 사진(폴더당 최대 1만 장)을 한 장씩 넘겨 보면서, GOOD 처리할 사진만 `Space`로 골라내고 **GOOD 목록 / REJECT 목록**을 텍스트 파일 2개로 저장합니다.

### 설치 / 실행
1. 아래 `AOI_Photo_Sorter_v1.zip`을 받아 로컬 폴더에 압축을 풉니다.
2. `AOI_Photo_Sorter_v1.vbs`를 더블클릭합니다.
3. 최초 1회만 실행 환경이 설치됩니다. AOI Matcher / Wafer Map Converter를 이미 쓰는 PC는 공용 환경을 재사용하므로 몇 초면 끝납니다.

필요 조건: Windows 10/11, WebView2 Runtime, Python 3.9~3.14(없으면 자동 설치 안내)

### 사용 순서
1. 시작 화면에서 **사진 폴더**와 **결과 저장 위치**를 지정합니다. 저장 위치는 시작할 때 쓰기 가능 여부를 확인하고, 다음 실행 때도 기억합니다.
2. 모든 사진은 REJECT 상태로 시작합니다. `→` 다음, `←` 이전, `Space` GOOD 지정/해제
3. 확인 화면에서 GOOD 목록 썸네일을 확인하고, 클릭이나 `Space`로 해제할 수 있습니다.
4. `Ctrl+S`로 저장하면 `<사진폴더명>_GOOD.txt`, `<사진폴더명>_REJECT.txt`가 만들어집니다. 한 줄에 파일 이름 1개씩, 탐색기 순서, UTF-8 형식입니다.

| 키 | 동작 |
|---|---|
| `→` / `←` | 다음 / 이전 사진 |
| `Space` | 지금 보이는 사진 GOOD 지정 ↔ 해제 |
| `F`, 휠, 드래그 | 100% 보기 / 화면 맞춤, 확대, 이동 |
| `Home` / `End` | 첫 사진 / 작업 위치(아직 안 본 첫 사진) |
| `Esc` | 메뉴 (확인 화면으로 / 처음 화면으로) |

### 특징
- **느린 네트워크 폴더 대응**: 사진 목록만 읽고 바로 시작합니다. 현재 위치 앞 200장 / 뒤 50장은 8개 스레드가 병렬로 미리 읽습니다. 1만 장을 끝까지 넘겨도 메모리 사용량은 일정합니다.
- **빠른 연타 안정성**
  - `Space`는 지금 화면에 그려진 사진에만 적용됩니다.
  - 아직 뜨지 않은 사진은 건너뛰지 않습니다.
  - 키를 누르고 있거나 두 번 튀어 눌려도 한 번만 처리됩니다.
  - 한/영, CapsLock 상태와 상관없이 동작합니다.
- **진행 상황 자동 저장**: 1초 단위로 저장합니다. 프로그램이 꺼져도 같은 폴더를 다시 열면 이어서 할 수 있습니다.
- **미확인 사진 경고**: 화면에 한 번도 뜨지 않은 사진이 있으면 저장 전에 알려 주고, [미확인 사진 보기]로 해당 사진만 볼 수 있습니다.

### 검증
- 측정 환경: Linux, Chromium headless(WebView2와 같은 엔진). 네트워크 폴더는 파일당 15~25 ms 지연을 넣은 모의 환경입니다.

| 항목 | 결과 |
|---|---|
| 1만 장 폴더: 시작 → 첫 사진 | 0.33초 |
| 키 입력 → 사진 표시 | p50 7 ms / p95 15 ms |
| 초당 20회 `→`/`Space` 연타 | 무시된 입력 0건 |
| 무작위 1,000회 연타 | 화면에 없는 사진이 GOOD으로 지정된 경우 0건, 화면·자동 저장·결과 파일 일치 |

- 단위 테스트와 Chromium E2E 테스트를 모두 통과한 빌드만 이 릴리스로 게시됩니다(Release 워크플로).
- **Windows 실기에서는 아직 확인하지 않았습니다.** 실제 네트워크 폴더에서의 속도, 폴더 선택 창, 사내 보안 프로그램의 127.0.0.1 통신 허용 여부는 실사용 중 확인이 필요합니다. 문제가 생기면 `%LOCALAPPDATA%\AOI_Tools\logs\AOI_Photo_Sorter.log`를 함께 전달해 주세요.
