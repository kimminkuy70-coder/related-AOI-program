## AOI Photo Sorter v3 — 네트워크 폴더 연결이 끊겨도 이어서 작업

작업 중 네트워크 폴더 연결이 끊겼다가 돌아오면 자동으로 이어지고, 필요하면 **F5(새로고침)** 한 번으로 정상 상태로 돌아옵니다. 설치와 사용법은 v2와 같습니다. `AOI_Photo_Sorter_v3.zip`을 새 폴더에 풀고 `AOI_Photo_Sorter_v3.vbs`를 실행하세요. 진행 중이던 작업(이어하기)과 저장 위치 설정은 그대로 이어집니다.

### 바뀐 점
- **연결 끊김 감지**: 사진 읽기에 실패하면 사진 폴더 자체에 접근되는지 확인해서, "네트워크 연결 끊김"과 "파일 하나의 문제"를 구분합니다.
- **끊긴 동안**
  - 이미 미리 읽어 둔 사진(앞쪽 최대 200장)은 계속 볼 수 있습니다.
  - 아직 읽지 못한 사진은 기다리지 않고 바로 "네트워크 폴더 연결 끊김" 카드가 뜹니다.
  - 화면 위쪽에 빨간 안내가 뜹니다.
  - 끊긴 공유 폴더에 읽기를 계속 시도하지 않고, 2초마다 연결만 확인합니다.
- **연결이 돌아오면 자동 복구**
  - 끊긴 동안 실패한 사진을 모두 자동으로 다시 읽습니다.
  - 보고 있던 사진과 확인 화면의 썸네일이 키를 누르지 않아도 다시 뜹니다.
- **F5 새로고침** (`R`, `Ctrl+R`도 같음, Esc 메뉴에도 있음): 네트워크 폴더에 바로 다시 연결하고, 읽기 실패한 사진을 모두 다시 읽습니다. 자동으로 돌아오지 않는 경우(일부 파일만 실패 등)에 사용합니다. 시작 화면에서는 경로를 다시 확인합니다.
- **응답 없음 표시**: 공유 폴더가 응답 없이 멈춰 있으면(5초 이상) 위쪽에 노란 "응답 대기 중" 안내가 뜹니다.
- 끊긴 동안 건너뛴 사진은 '미확인'으로 남습니다. `End` 키나 확인 화면의 [미확인 사진 보기]로 다시 볼 수 있습니다. 진행 기록은 PC에 저장되므로 끊겨도 잃지 않습니다.

### 검증
- 측정 환경: Linux, Chromium headless(WebView2와 같은 엔진). 공유 폴더 끊김·복구·응답 없음은 모의로 재현했습니다.

| 상황 | 결과 |
|---|---|
| 끊긴 직후 미리 읽은 사진 30장 넘기기 | 전부 정상 표시 |
| 끊긴 뒤 아직 읽지 못한 사진 | 2.0초 만에 "연결 끊김" 카드. 그다음 사진부터는 1초 안에 표시 |
| 연결 복구 | **키 입력 없이 2.7초 만에** 보던 사진이 다시 뜸. 이후 10장 정상, `End`로 끊긴 동안 건너뛴 사진으로 이동해 정상 표시 |
| 확인 화면 썸네일 (끊긴 동안 실패) | 복구 2.0초 뒤 자동으로 다시 뜸 |
| 일부 파일만 실패(폴더는 정상) | 자동 재시도 없이 "읽기 실패" 유지 → **F5** 한 번으로 다시 읽어 정상 표시 |
| 응답 없이 멈춘 읽기 | 수 초 뒤 "응답 대기 중" 안내 → 풀리면 사진 표시, 안내 사라짐 |

- 단위 테스트와 Chromium E2E 테스트(연타·1만 장·끊김/복구/F5 포함)를 모두 통과한 빌드만 게시됩니다.
- **Windows 실기와 실제 공유 폴더에서는 아직 확인하지 않았습니다.** 실제 Windows 공유 폴더는 끊길 때 수십 초 응답이 없을 수 있습니다. 그동안에는 "응답 대기 중"이 표시되고, 끊김이 확인되면 위 동작으로 이어집니다. 문제가 생기면 `%LOCALAPPDATA%\AOI_Tools\logs\AOI_Photo_Sorter.log`를 함께 전달해 주세요.
