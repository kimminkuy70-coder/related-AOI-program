## AOI Photo Sorter v7 — .exe 오탐(바이러스 오경보) 완화

### 바뀐 점
- v6부터 추가한 설치 없는 `AOI_Photo_Sorter_v7.exe`가 일부 PC에서 Windows Defender에 `트로이 목마`(예: `Trojan:Win32/Wacatac`)로 **오탐(false positive)** 되던 문제를 줄였습니다.
  - 이것은 코드에 악성 요소가 있어서가 아니라, 서명되지 않은 PyInstaller one-file 실행 파일에서 흔히 생기는 오경보입니다. PC마다 Defender 정의·클라우드 상태가 달라 "어떤 사람은 되고 어떤 사람은 안 되는" 현상이 생깁니다.
  - 한 번 그 파일이 격리되면 **같은 파일을 다시 받아도 압축을 풀자마자 즉시 차단**됩니다(해시가 차단 목록에 올라감). v7은 바이트가 다른 새 파일이라 이 차단과 무관하게 받습니다.
- 빌드 방식 변경(프로그램 기능·사용법은 v6과 같습니다):
  - **PyInstaller 런처 스텁(bootloader)을 빌드 머신에서 소스로 다시 컴파일**합니다. 여러 패키지에서 똑같이 쓰여 널리 탐지되는 기본 스텁 대신, 이 빌드만의 바이트가 들어갑니다.
  - **Windows 버전 정보(회사·제품·버전)**를 .exe에 넣어, 메타데이터 없는 미서명 파일이 휴리스틱에서 더 의심받는 것을 줄였습니다(파일 속성 → 자세히에서 확인).
  - **UPX 압축을 끕니다**(압축된 .exe가 더 자주 탐지됨).

### 그래도 오탐이 나면
- 가장 확실한 해결책은 **코드 서명 인증서(Authenticode)로 .exe를 서명**하는 것입니다(인증서가 필요해 자동 빌드에는 포함하지 못했습니다).
- 사내 배포라면 IT에 **Defender 허용 등록(파일 해시 또는 배포 폴더 예외)**을 요청하면 즉시 해결됩니다.
- `AOI_Photo_Sorter_v7.zip`(.vbs + 공용 Python 환경) 방식은 PyInstaller .exe가 아니라 오탐 대상이 아니므로, 급할 때 대안으로 쓸 수 있습니다.

### 검증
- `tools/build_exe.py`의 변경(스텁 소스 컴파일 확인, `--noupx`, 버전 리소스 삽입)과 매니페스트 v7 반영.
- 기존 단위·화면·.exe 자체 시험은 v6과 동일하게 통과한 빌드만 게시됩니다.
- 실제 Windows에서의 오탐 감소 효과는 배포 후 사용 PC에서 확인이 필요합니다(Linux 빌드 환경에서는 Defender 결과를 검증할 수 없습니다).
