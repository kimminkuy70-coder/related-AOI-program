## AOI Photo Sorter v8 — 폴더 끝에서 Enter로 다음 폴더, 전체 결과(GOOD / REJECT) 한 번에 보기, 사진 경로 패널

### 다운로드
- **`AOI_Photo_Sorter_v8.exe`** — 설치 없이 바로 실행합니다(v7과 같은 방식으로 빌드).
- `AOI_Photo_Sorter_v8.zip` — 기존 방식(.vbs + 공용 Python 환경)입니다.
- 설정, 진행 상황, 결과 파일 규칙은 v7과 같습니다. 이어서 쓰면 됩니다.

### 한 폴더를 다 보면 Enter로 다음 폴더 (상위 폴더 작업)
- 상위 폴더 목록에서 연 하위 폴더를 끝까지 보면(마지막 사진에서 `→` / `Space` / `Enter`) **"이 폴더의 마지막 사진입니다"** 창이 뜹니다.
  - **`Enter`**: 이 폴더를 n차리뷰로 저장하고 **바로 다음 하위 폴더로 넘어가** 이어서 분류합니다. 다음 폴더 화면 아래에 이전 폴더 저장 결과(GOOD / REJECT 수)가 잠깐 표시됩니다.
  - `C`: 확인 화면으로, `Esc`: 창을 닫고 계속 보기.
  - 미확인 사진이 있으면 창에 개수가 표시되고, 저장하면 REJECT로 들어갑니다.
- 마지막 폴더에서는 저장한 뒤 아래 **전체 결과** 화면이 열립니다.
- 폴더 하나만 직접 지정한 경우는 v7과 같습니다(마지막 사진에서 Enter → 확인 화면).

### 전체 결과 보기 (상위 폴더의 GOOD / REJECT 한 번에)
- 모든 하위 폴더의 결과(폴더마다 저장한 가장 큰 n차리뷰)를 한 화면에서 썸네일로 봅니다.
- 위쪽 **[GOOD] / [REJECT]**(키 `1` / `2`, `Tab`)로 바꿉니다. 썸네일마다 파일 이름과 하위 폴더 이름이 나옵니다.
- 왼쪽 목록에 전체와 폴더별 GOOD·REJECT 수가 나오고, 클릭(또는 `PageUp`/`PageDown`)하면 그 폴더 사진만 봅니다. 저장하지 않은 폴더는 "저장 안 됨"으로 표시됩니다.
- `Enter`(또는 더블클릭)로 크게 보기, 크게 보기에서 `←` `→` 이전/다음, `Esc` 닫기.
- 고른 사진의 전체 경로가 아래에 나오고 [경로 복사]로 복사할 수 있습니다.
- 여는 곳: 마지막 폴더 저장 후 자동, 시작 화면 하위 폴더 목록의 [전체 결과 보기], 완료 화면, 선별 화면 Esc 메뉴(`O`).

### 사진 경로 패널 (선별 화면 왼쪽)
- 지금 사진의 **폴더 / 파일 이름 / 전체 경로**를 왼쪽에 표시합니다. 위쪽 [경로 패널 ON/OFF]로 켜고 끄며, 설정은 기억합니다.
- 글자를 **마우스로 끌어 선택**하고 `Ctrl+C`(또는 오른쪽 클릭 → 복사)로 복사할 수 있습니다(이전에는 선별 화면에서 글자 선택·드래그가 막혀 있었습니다). [경로 복사] 버튼은 전체 경로를 복사합니다.
- **[이 사진 파일 끌어 놓기]** 칸을 탐색기 폴더나 바탕화면에 끌어 놓으면 사진 파일이 복사됩니다. 글자 입력칸에 놓으면 전체 경로가 들어갑니다.
- 상위 폴더 작업 중에는 하위 폴더 목록과 지금 폴더가 함께 표시됩니다.

### 검증
- 단위 테스트: 전체 결과 목록(저장한 회차·GOOD/REJECT 이름, 저장 안 된 폴더), 썸네일·원본을 번호로만 제공, 사라진 사진은 오류 응답, 파일 끌어 놓기용 원본 전송, 경로 패널 설정 유지.
- 화면 테스트(Chromium): 마지막 사진에서 창 → Esc 계속 → Enter 저장 후 다음 폴더 → 마지막 폴더 저장 후 전체 결과(GOOD/REJECT 전환, 폴더별 보기, 크게 보기) → 폴더 목록 복귀. 기존 연타·1만 장·네트워크 끊김 테스트 포함 전체 통과.
- 실제 Windows(WebView2)에서의 파일 끌어 놓기(탐색기로 복사)와 클립보드 복사는 이 빌드 환경(Linux)에서 확인할 수 없어 배포 후 확인이 필요합니다. 끌어 놓기가 안 되면 [경로 복사] 후 탐색기 주소창에 붙여 넣어 쓰세요.
