## AOI Photo Sorter v6 — 상위 폴더(하위 폴더별 작업), 설치 없는 .exe

### 다운로드
- **`AOI_Photo_Sorter_v6.exe`** — 설치 없이 바로 실행합니다. Python이나 패키지를 설치할 필요가 없고, Windows 10/11에 있는 WebView2 Runtime만 씁니다. 다른 사람에게 줄 때는 이 파일 하나만 주면 됩니다.
  - 처음 실행할 때 "Windows의 PC 보호"(SmartScreen) 창이 뜨면 [추가 정보] → [실행]을 누르세요. 코드 서명이 없는 사내용 프로그램이라 나타날 수 있습니다.
  - 실행할 때마다 임시 폴더에 풀어서 실행하므로, 창이 뜨기까지 1~3초 걸릴 수 있습니다.
- `AOI_Photo_Sorter_v6.zip` — 기존 방식(.vbs + 공용 Python 환경)입니다.
- 설정, 진행 상황, 결과 파일 규칙은 두 버전이 같습니다. 번갈아 써도 이어집니다.

### 상위 폴더로 하위 폴더별 작업
- ① 사진 폴더에 상위 폴더(예: LOT 폴더)를 지정하면 그 아래 사진이 있는 폴더(4단계까지)를 모두 찾아 목록으로 보여 줍니다.
  - 네트워크 폴더는 하위 폴더를 동시에 여러 개 읽고, 찾는 대로 목록에 추가합니다.
  - 폴더마다 사진 수와 상태(미작업 / 진행 중 / n차리뷰 저장 / 추가 검토 중)가 표시됩니다.
- `↑` `↓`로 고르고 `Enter`(또는 더블클릭)로 시작합니다. 고른 폴더 기준으로 저장 파일 이름, 이어하기, 추가 GOOD 검토가 표시됩니다.
- 하위 폴더 하나가 작업 하나입니다. 진행 상황, 회차, 추가 GOOD 검토가 폴더마다 따로입니다.
- 저장하면 완료 화면의 **[다음 폴더 (Enter)]**로 바로 다음 하위 폴더를 시작합니다. Esc 메뉴에도 [다음 폴더 (N)], [폴더 목록으로]가 있습니다.
- 선별 화면 위쪽에 `상위폴더 › 하위폴더 (k/전체)`가 표시됩니다.
- 결과 파일 이름은 `<상위폴더명>_<하위폴더명>_<n>차리뷰_<날짜>_<시각>_<종류>.txt`입니다. 예: `LOT123_Top_1차리뷰_20261014_0915_GOOD.txt`
  - 결과 폴더 하나에 여러 LOT의 같은 이름 하위 폴더(Top, Bottom 등)가 있어도 섞이지 않습니다.
  - 하위 폴더를 상위 폴더 없이 직접 지정하면 v5와 같이 폴더명만으로 이름을 만듭니다.
- 목록을 만들 때 읽은 사진 목록을 1분 동안 재사용하므로, 고르고 바로 시작하면 폴더를 다시 읽지 않습니다.

### 기타
- 시작 화면의 버전 표시가 실행 파일의 버전을 따릅니다(v5 화면에 v4로 보이던 문제 수정).

### 검증
- 단위 테스트
  - 하위 폴더 찾기: 순서, 숨김 폴더 제외, 깊이 제한, 열 수 없는 폴더, 취소
  - 결과 이름 규칙과 결과 폴더 색인
  - 서버: 목록 상태, 다시 읽지 않기, 같은 회차 다시 저장, 직접 연 경우 이름
- 화면 테스트 (Chromium)
  - 상위 폴더 목록 → ↑↓ 선택 → 저장 → 다음 폴더(Enter) → 목록 상태 표시 → 더블클릭 시작
- .exe: Windows 빌드 머신에서 만든 .exe를 그대로 실행해 자체 시험을 통과한 것만 게시됩니다.
  - 패키지와 화면 파일 포함, 사진 폴더 정리·저장
  - WebView2 창에서 화면이 실행되는지 확인
- 기존 연타, 1만 장, 네트워크 끊김 테스트를 포함해 모두 통과한 빌드만 게시됩니다.
