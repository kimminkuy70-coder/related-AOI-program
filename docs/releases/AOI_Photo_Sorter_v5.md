## AOI Photo Sorter v5 — 결과 파일을 n차리뷰로 정리

결과 파일 이름에 **회차(n차리뷰)와 저장 날짜·시각**이 들어가고, 저장할 때마다 그 회차 파일을 새로 만듭니다. 이전 회차 파일은 건드리지 않습니다. 그래서 v4의 `_이전_` 백업 파일은 더 이상 생기지 않습니다. 설치와 사용법은 v4와 같습니다. `AOI_Photo_Sorter_v5.zip`을 새 폴더에 풀고 `AOI_Photo_Sorter_v5.vbs`를 실행하세요.

### 결과 파일
이름: `<사진폴더명>_<n>차리뷰_<날짜>_<시각>_<종류>.txt`

| 회차 | 만드는 파일 |
|---|---|
| 1차리뷰 (처음 전체 리뷰) | `GOOD` — 고른 사진, `REJECT` — 나머지 |
| 2차리뷰부터 (추가 GOOD 검토) | `추가GOOD` — 이번 회차에서 새로 GOOD이 된 사진만, `GOOD` — 이전 GOOD과 이번 추가를 합친 전체, `REJECT` — 남은 사진 |

예시 (3회차까지):
```
LOT123_1차리뷰_20261010_0915_GOOD.txt
LOT123_1차리뷰_20261010_0915_REJECT.txt
LOT123_2차리뷰_20261010_1029_추가GOOD.txt
LOT123_2차리뷰_20261010_1029_GOOD.txt
LOT123_2차리뷰_20261010_1029_REJECT.txt
LOT123_3차리뷰_20261010_1030_추가GOOD.txt
LOT123_3차리뷰_20261010_1030_GOOD.txt
LOT123_3차리뷰_20261010_1030_REJECT.txt
```
- **가장 큰 n이 최신**입니다. 탐색기 이름순 정렬로 회차 순서대로 보입니다(10차도 9차 다음).
- 추가 GOOD 검토는 결과 폴더에서 가장 큰 회차를 자동으로 찾아 이어 갑니다. 시작 화면에 "이전 결과: n차리뷰"와 "→ (n+1)차리뷰"가 표시됩니다.
- 같은 작업에서 다시 저장하면(확인 화면에서 고친 뒤 Ctrl+S 등) 새 회차를 만들지 않고 그 회차 파일을 갱신합니다.
- 검토하는 사이에 다른 PC가 더 높은 회차를 저장했으면 저장 전에 알립니다. 그 회차의 GOOD에 이번 추가 GOOD을 합쳐 다음 번호로 저장합니다.
- 결과가 있는 폴더에서 전체 리뷰를 처음부터 다시 하면 다음 번호로 저장되고, 파일은 GOOD/REJECT 2개만 만듭니다.
- **v4 결과 파일**(`<사진폴더명>_GOOD.txt` 등)은 이전 결과로 그대로 읽습니다. 지우거나 바꾸지 않으며, 다음 저장부터 새 규칙을 씁니다. v4 추가 검토 이력이 있으면 그 횟수만큼 회차를 이어서 셉니다.
- 파일 내용은 그대로입니다. 한 줄에 사진 이름 1개씩, 폴더 정렬 순서, UTF-8, CRLF입니다.

### 검증
- 단위 테스트
  - 회차 이름과 저장 내용
  - 같은 작업에서 다시 저장할 때 같은 회차 갱신
  - 최신 회차 판정(10차가 9차보다 최신, GOOD/REJECT가 다 없는 회차 제외, 다른 폴더 결과 무시)
  - v4 파일 읽기와 보존
  - 다른 PC가 먼저 저장했을 때 합치기
- 화면 테스트 (Chromium)
  - v4 결과로 추가 검토를 해서 2차리뷰 3개 파일 생성
  - 1차 → 2차 → 확인 화면에서 고쳐 다시 저장 → 같은 2차 파일 갱신(3차 안 생김)
- 기존 연타·1만 장·네트워크 끊김 테스트 포함, 모두 통과한 빌드만 게시됩니다. Windows 실기 확인은 아직입니다.
