## AOI Photo Sorter v2 — Space 한 번으로 GOOD + 다음 사진

v1 사용 피드백을 반영한 버전입니다. 설치와 사용법은 v1과 같습니다. `AOI_Photo_Sorter_v2.zip`을 새 폴더에 풀고 `AOI_Photo_Sorter_v2.vbs`를 실행하세요. 이전 진행 기록(이어하기)과 저장 위치 설정은 그대로 이어집니다.

### 바뀐 점
- **`Space` = GOOD + 다음 사진**: GOOD 처리할 사진에서 `Space` 한 번이면 GOOD으로 바뀌고 바로 다음 사진으로 넘어갑니다. `→`를 따로 누르지 않아도 됩니다.
  - 이미 GOOD인 사진에서 `Space`를 누르면 GOOD이 해제되고 다음 사진으로 넘어갑니다. 잘못 누른 사진은 `←`로 돌아가 `Space`를 누르면 됩니다.
  - 확인 화면의 썸네일에서도 `Space`를 누르면 GOOD이 해제되고 다음 칸으로 이동합니다.
- **GOOD 이펙트 최소화**: 화면 전체를 덮던 반짝임 효과와 초록 테두리를 없앴습니다. GOOD 사진에는 왼쪽 위의 작은 "GOOD" 표시와 아래쪽 상태 글자만 남습니다. 상단·하단 정보 줄도 바뀐 값만 다시 그리도록 해서 키를 누를 때마다 하는 화면 작업을 줄였습니다.
- **두 번 눌림 보호 방식 변경**: Space를 누르면 다음 사진으로 넘어가므로, 키가 튀거나 겹쳐 눌리면 방금 넘어온 사진까지 GOOD이 될 수 있습니다. 그래서 사진이 화면에 뜬 지 0.12초가 안 된 상태의 Space는 무시합니다. 설정 `space_min_view_ms`로 조정할 수 있습니다(v1의 `space_debounce_ms`를 대체).

### 검증
- 측정 환경: Linux, Chromium headless(WebView2와 같은 엔진). 네트워크 폴더는 파일당 15~20 ms 지연을 넣은 모의 환경입니다.

| 항목 | 결과 |
|---|---|
| `Space` → 다음 사진이 그려진 프레임 (80회) | p50 24 ms / p95 37 ms |
| `→` 초당 20회 + 4장마다 GOOD 300회 입력 | 무시된 입력 0건, GOOD 75장 정확 |
| 5 ms 간격 무작위 1,000회 (누르고 있기, 동시 입력 포함) | 화면에 0.12초 미만 떠 있던 사진의 GOOD 지정 0건, Space 후에는 항상 다음 사진으로 이동, 화면·자동 저장·결과 파일 일치 |
| 1만 장 폴더 | 첫 사진 0.35초, `→` p50 7 ms / p95 15 ms |

- 원본 사진은 읽기만 합니다. 결과 txt는 지정한 저장 위치에만 만듭니다.
- **Windows 실기에서는 아직 확인하지 않았습니다.** 문제가 생기면 `%LOCALAPPDATA%\AOI_Tools\logs\AOI_Photo_Sorter.log`를 함께 전달해 주세요.
